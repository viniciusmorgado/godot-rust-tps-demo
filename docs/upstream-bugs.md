# Upstream bugs fixed in v1

Record required by constitution v1.3.0 (Principle I, conservative upstream bug fix clause). Each
entry is a **minimal** fix of an objective defect of the original Godot TPS Demo — behavior the
code itself clearly intended and did not deliver — declared in the feature's spec, isolated in the
code by a `// upstream bug fix: ...` comment at the exact spot and mentioned in the commit message.
It serves as a reference for v2 and for a possible upstream contribution. Improvements do not go
here: they go to `docs/v2-backlog.md`.
